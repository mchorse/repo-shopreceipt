# ShopReceipt

ShopReceipt is a simple client-side mod that displays a list of items in the shop's extraction point, with their cost (color-graded by price) and counts.

# Чек магазина

Это простой клиентский мод, который показывает список предметов, в пункте экстракта в магазине, их стоимость (с градиентом по цене) и количеством.
